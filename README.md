Elevador : 
Aplicação que simula o funcionamento e o controle de um sistema de elevador. O código é estruturado para gerenciar a lógica de movimentação entre andares, 
controle de capacidade de passageiros (entrada e saída) e gerenciamento da fila de chamadas em ordem de prioridade.

Conversor Romano : 
Módulo responsável por realizar a conversão bidirecional entre números inteiros decimais e algarismos romanos (ex: 42 ⇄ XLII). 
O projeto foca em lógica de manipulação de strings e estruturas condicionais/dicionários para validar e processar os símbolos numéricos.

Gerador de Senhas : 
Utilitário para criação de senhas aleatórias e seguras. O código permite ao usuário definir parâmetros como tamanho da senha e inclusão de caracteres especiais,
números, letras maiúsculas e minúsculas, utilizando algoritmos de aleatoriedade para garantir maior segurança.
